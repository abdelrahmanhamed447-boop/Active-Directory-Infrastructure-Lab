# Active Directory Infrastructure Lab

A hands-on Windows Server 2025 lab focused on designing and implementing an Active Directory infrastructure environment.

## Project Overview

This project demonstrates the implementation of a Windows Server 2025 Active Directory environment, including domain services, DNS, organizational structure, user and group management, and Group Policy configuration.

## Active Directory Components

The lab includes:

- Domain Controller
- Active Directory Domain Services (AD DS)
- DNS
- Organizational Units (OUs)
- User Accounts
- Security Groups
- Group Policy Management

## Key Configuration

### Domain Controller

Implemented a Windows Server 2025 Domain Controller to provide centralized Active Directory services and domain management.

### DNS

Configured DNS as part of the Active Directory environment to support domain name resolution and Active Directory services.

### Organizational Units

Created Organizational Units (OUs) to organize and manage users and groups within the Active Directory environment.

### Users and Groups

Configured user accounts and groups to demonstrate centralized identity and access management within the domain.

### Group Policy

Implemented Group Policy management to apply centralized administrative policies across the Active Directory environment.
